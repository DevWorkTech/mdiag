# MDiag DWT

Изолированный Laravel-пакет `devworktech/mdiag-dwt` для локальной библиотеки диагностических пакетов.

- Namespace `DevWorkTech\MDiag`, конфиг `mdiag-dwt`, таблицы `mdiag_*`, команды `mdiag:*`.
- Локальные пользователи/пароли и сессии независимы от аккаунта поставщика.
- HTTP-контур не имеет proxy/fallback в Интернет. Неизвестные операции возвращают локальную ошибку.
- Активность, срок подписки, whitelist модулей и привязка сканера проверяются при каждом запросе.
- Персональные пакеты разделены по SN источника; сервер не изменяет лицензии внутри файлов.
- Консольная синхронизация использует только `MDIAG_XDIAG_LOGIN` / `MDIAG_XDIAG_PASSWORD` владельца.
- SOAP синхронизации работает без предварительного GET WSDL. Дополнительный вход требует настроенного SN.
- IP сервера хранится только в DNS роутера; Laravel/APK используют домен.

Установка и команды: [INSTALL_SERVER_RU.md](INSTALL_SERVER_RU.md).
Протокол и ограничения: [server/PROTOCOL_RU.md](server/PROTOCOL_RU.md).

HTTP-адаптер обновлён по X-DIAG 7.00.014. Остальные профили отключены до анализа их APK.
Полная работа всех экранов оригинального приложения ещё требует проверки на устройстве.
Произвольные сообщения доступны в ответах, но некоторые экраны APK заменяют их встроенными строками.
Файлы сторонних библиотек и штатные проверки внутри диагностических модулей не изменяются.

Для запрета любого внешнего трафика планшета используйте firewall роутера: Android SDK внутри APK
могут иметь независимые адреса, не проходящие через Laravel. Доменная замена не является firewall.

Тесты: `cd server && composer install && composer test`.
Сборка APK: workflow `Build mX-DIAG APK`; параметр `lan_domain` должен совпадать с конфигом.
Новые имена signing secrets: `MDIAG_KEYSTORE_BASE64`, `MDIAG_STORE_PASSWORD`, `MDIAG_KEY_ALIAS`, `MDIAG_KEY_PASSWORD`.

## Android-клиент mX-DIAG

Репозиторий: https://github.com/DevWorkTech/mdiag. Клиент: **mX-DIAG 7.00.014**,
applicationId `tech.devwork.mxdiag`, каталог данных `mXDiagPro3`. Исходный APK закреплён по SHA-256.
PHP принимает штатные SOAP-подписи, API user_id/sign и download-заголовки cc/sign.
Скачивание, HEAD и Range проходят проверки доступа и обслуживаются PHP; прямой статической раздачи нет.
Полное совпадение всех экранов закрытого приложения с официальным сервером не заявляется:
требуется проверка на реальном планшете, а неподдержанные операции возвращают локальную ошибку.
