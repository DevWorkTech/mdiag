# Локальная ремонтная информация

```bash
php artisan optimize:clear
php artisan mdiag:sync xdiag --content=repairdata --list
php artisan mdiag:sync xdiag --content=repairdata
```

Теперь сохраняется HTML с локальными ссылками, CSS, JS и изображениями вместо
текста current.txt. Старый текстовый снимок нужно синхронизировать заново.
Страница: /xdiag/repairdata/newmain/; ресурсы: /xdiag/repairdata/<исходный путь>.
Файлы выдаются PHP из private storage, не исполняются как PHP. HTTP-маршруты
не запрашивают официальный сайт. Отсутствующий ресурс возвращает 404 с сообщением,
не редирект на внешний сервер. POST пока возвращает 501: серверные функции
поставщика требуют собственного адаптера, их поведение не выдумывается.

301/302/303/307/308 обрабатываются только CLI, не более 5 переходов. Каждый адрес
проверяется до запроса: только http/https, тот же разрешённый hostname, стандартный
порт, без userinfo. Переход на другой хост отклоняется с его адресом для проверки
оператором. Cookie и учётные данные локальных пользователей не передаются.

Лимиты снимка: 128 ресурсов, глубина ссылок 3, ресурс 8 MiB, общий объём 64 MiB.
Query входит в ключ ресурса. Стартовая страница доступна также без source=app.
Версии сохраняются по SHA-256; current.json переключается атомарно после успешной
загрузки. Ошибка и парковочная страница не заменяют предыдущий снимок.

Снимок — не полная эмуляция сайта. Динамический JavaScript, AJAX, поиск, сессии,
формы, CSS @import без url(), srcset и серверная база могут требовать адаптера.
CSP запрещает внешние ресурсы/запросы; отсутствующие локальные API не подменяются
успешным ответом. FAQ и остальные разделы требуют подтверждённых источников.

При проверке 23.09.2026 запрос http://repairdata.xdiagpro.com/newmain/?source=app
из среды разработки вернул страницу продажи домена xdiagpro.com, а не базу.
Это не доказывает одинаковый ответ из всех сетей. Такой ответ синхронизация
явно отклоняет. Для воспроизведения раздела 1:1 нужен рабочий источник/архив
и реальные ответы API; заглушка или парковочная страница его не заменяет.
